# v9 breaking-change register

Update this register with every public API break as it lands. Each row must link
to its dedicated section in `docs/introduction/migrate-from-v8.md` before an
alpha release is ready.

| Surface                                                      | v8 behavior                                                                                                                              | v9 behavior                                                                                                                        | Migration                                                                                                                                               | Validation                                               | Commit / PR                |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------- |
| `IncomingEvent`                                              | Exported Node-default `{request, response}` event type.                                                                                  | Removed in favor of the runtime-agnostic `PlatformNativeContext`.                                                                  | Import `PlatformNativeContext` from `@tsed/platform-http`; provide the host request and response through it.                                            | `PlatformContext.spec.ts`, `PlatformResponse.spec.ts`    | `bc28a631f6`               |
| `PlatformResponse` host writes                               | Mutation methods immediately called Express/Koa/Fastify response methods.                                                                | Mutation only changes portable Fetch state; the bridge writes the single response returned by `finalize()`.                        | Replace assertions or custom response code that relies on immediate `res` mutation with `PlatformResponse` state or a host `native` middleware.         | `PlatformResponse.spec.ts`                               | `78ee3242c7`               |
| Adapter response subclasses                                  | `PlatformExpressResponse`, `PlatformFastifyResponse`, and `PlatformKoaResponse` were public adapter-specific `PlatformResponse` classes. | Removed; all first-party adapters use `PlatformResponse`.                                                                          | Import and provide `PlatformResponse`; use `response.native` for a deliberate host-specific integration.                                                | `PlatformResponse.spec.ts`, `PlatformMcpModule.spec.ts`  | `736fa02e61`               |
| `PlatformResponse.cookie()`                                  | Cookie values were immediately serialized or written by the response facade.                                                             | The facade stores a host-neutral mutation; `writeFetchResponse($ctx)` delegates to the active host cookie capability exactly once. | Keep using `response.cookie()`, but install the relevant Express, Fastify, or Koa cookie middleware/plugin; do not read a portable `Set-Cookie` header. | `PlatformResponse.spec.ts`, bridge writer specs          | `449b5d05ee`, `5746da32a4` |
| `PlatformResponse.stream()`                                  | Accepted Node streams through the portable response.                                                                                     | Accepts only the standard Web `ReadableStream`; Node stream conversion is a bridge/native capability.                              | Convert the stream in the host bridge or use the host response through `response.native`.                                                               | `PlatformResponse.spec.ts`                               | `c9bd0060ab`               |
| `PlatformContext.getReq()` / `getRes()`                      | Returned Node `IncomingMessage` / `ServerResponse` types.                                                                                | Return explicit generic host-native values.                                                                                        | Type native host access as `ctx.getReq<Express.Request>()` or use `ctx.request.native` / `ctx.response.native`.                                         | `PlatformRequest.spec.ts`, `PlatformContext.spec.ts`     | `b641429ef8`               |
| `PlatformApplication.callback()`                             | Was typed as a Node HTTP request listener.                                                                                               | Is typed as a generic host callback; Fetch execution will use the separate `Request -> Response` handler.                          | Type a Node callback at the Node bridge boundary instead of relying on `PlatformApplication`.                                                           | `PlatformApplication.spec.ts`, `PlatformBuilder.spec.ts` | `b04616ba2c`               |
| `PlatformAdapter.createApp()` / `PlatformBuilder.callback()` | Advertised Node `IncomingMessage` / `ServerResponse` callback signatures through the portable adapter base.                              | Advertise a generic host callback; Node bridges keep their concrete callback types internally.                                     | Type Node callbacks in a Node bridge rather than through `@tsed/platform-http`.                                                                         | `PlatformBuilder.spec.ts`                                | `192d242b57`               |
