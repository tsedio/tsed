# v9 breaking-change register

Update this register with every public API break as it lands. Each row must link
to its dedicated section in `docs/introduction/migrate-from-v8.md` before an
alpha release is ready.

| Surface                                                      | v8 behavior                                                                                                                                                              | v9 behavior                                                                                                                                                                              | Migration                                                                                                                                                                                                              | Validation                                                       | Commit / PR                              |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------- |
| `IncomingEvent`                                              | Exported Node-default `{request, response}` event type.                                                                                                                  | Removed in favor of the runtime-agnostic `PlatformNativeContext`.                                                                                                                        | Import `PlatformNativeContext` from `@tsed/platform-http`; provide the host request and response through it.                                                                                                           | `PlatformContext.spec.ts`, `PlatformResponse.spec.ts`            | `bc28a631f6`                             |
| `PlatformRequest.native` / `raw`                             | Were typed as always-present host request aliases.                                                                                                                       | Are `undefined` during direct Fetch execution and typed accordingly; `raw === native` whenever a host bridge provides a request.                                                         | Guard native access or run it only in a host-specific integration; portable handlers use `request.fetch`.                                                                                                              | `PlatformRequest.spec.ts`                                        | `12e5bcdef6`                             |
| `PlatformResponse` host writes                               | Mutation methods immediately called Express/Koa/Fastify response methods.                                                                                                | Mutation only changes portable Fetch state; the bridge writes the single response returned by `finalize()`.                                                                              | Replace assertions or custom response code that relies on immediate `res` mutation with `PlatformResponse` state or a host `native` middleware.                                                                        | `PlatformResponse.spec.ts`                                       | `78ee3242c7`                             |
| Adapter response subclasses                                  | `PlatformExpressResponse`, `PlatformFastifyResponse`, and `PlatformKoaResponse` were public adapter-specific `PlatformResponse` classes.                                 | Removed; all first-party adapters use `PlatformResponse`.                                                                                                                                | Import and provide `PlatformResponse`; use `response.native` for a deliberate host-specific integration.                                                                                                               | `PlatformResponse.spec.ts`, `PlatformMcpModule.spec.ts`          | `736fa02e61`                             |
| `PlatformResponse.cookie()`                                  | Cookie values were immediately serialized or written by the response facade.                                                                                             | The facade stores a host-neutral mutation; `writeFetchResponse($ctx)` delegates to the active host cookie capability exactly once.                                                       | Keep using `response.cookie()`, but install the relevant Express, Fastify, or Koa cookie middleware/plugin; do not read a portable `Set-Cookie` header.                                                                | `PlatformResponse.spec.ts`, bridge writer specs                  | `449b5d05ee`, `5746da32a4`               |
| `PlatformResponse.stream()`                                  | Accepted Node streams through the portable response.                                                                                                                     | Accepts only the standard Web `ReadableStream`; Node stream conversion is a bridge/native capability.                                                                                    | Convert the stream in the host bridge or use the host response through `response.native`.                                                                                                                              | `PlatformResponse.spec.ts`                                       | `c9bd0060ab`                             |
| `PlatformContext.getReq()` / `getRes()`                      | Returned Node `IncomingMessage` / `ServerResponse` types.                                                                                                                | Return explicit generic host-native values.                                                                                                                                              | Type native host access as `ctx.getReq<Express.Request>()` or use `ctx.request.native` / `ctx.response.native`.                                                                                                        | `PlatformRequest.spec.ts`, `PlatformContext.spec.ts`             | `b641429ef8`                             |
| `PlatformApplication.callback()`                             | Was typed as a Node HTTP request listener.                                                                                                                               | Is typed as a generic host callback; Fetch execution will use the separate `Request -> Response` handler.                                                                                | Type a Node callback at the Node bridge boundary instead of relying on `PlatformApplication`.                                                                                                                          | `PlatformApplication.spec.ts`, `PlatformBuilder.spec.ts`         | `b04616ba2c`                             |
| `PlatformAdapter.createApp()` / `PlatformBuilder.callback()` | Advertised Node `IncomingMessage` / `ServerResponse` callback signatures through the portable adapter base.                                                              | Advertise a generic host callback; Node bridges keep their concrete callback types internally.                                                                                           | Type Node callbacks in a Node bridge rather than through `@tsed/platform-http`.                                                                                                                                        | `PlatformBuilder.spec.ts`                                        | `192d242b57`                             |
| `Use*` function middleware and `@Next()`                     | An unmarked function could be inferred as Express/Koa native middleware from its arity and received host `req`, `res`, and `next`; `@Next()` injected the host callback. | A zero- or one-argument function is a portable `(ctx) => Promise<void>` handler; two or more parameters retain native host middleware compatibility; Fetch middleware rejects `@Next()`. | Keep `@UseBefore((req, res, next) => {})` as a native callback (or wrap it in `native()` to make the boundary explicit); author portable middleware as `async (ctx) => { await ctx.next?.(); }` or a class `use(ctx)`. | `PlatformHandlerMetadata.spec.ts`, `executeFetchRoute.spec.ts`   | `a13b30a273`, `97964d1bf9`, `e125b56397` |
| Adapter `writeFetchResponse()` utilities                     | Accepted only a context and finalized its response implicitly.                                                                                                           | Require the already-finalized `Response` as a second argument.                                                                                                                           | Call `writeFetchResponse(ctx, ctx.response.finalize())` only at a legacy host boundary, or forward the response returned by `executeFetchContext()`.                                                                   | Adapter writer specs                                             | `625f06fdb3`                             |
| `PlatformHandler.finalizeResponse()`                         | Prepared and finalized the response behind one method.                                                                                                                   | Removed; `prepareResponse(ctx)` is explicit and the Fetch executor finalizes the draft visibly.                                                                                          | Call `await handler.prepareResponse(ctx)` then `ctx.response.finalize()` at the execution boundary.                                                                                                                    | `PlatformHandler.spec.ts`, `createFetchHandler.spec.ts`          | `47284d0fbe`                             |
| `PlatformHostBridge`                                         | Converted a native request to `Request` and wrote a `Response` against a separate native response value.                                                                 | Creates the native-capable `PlatformContext`, can reuse one with `getContext(native)`, and writes the finalized response with that context.                                              | Implement `createContext(native)`, optionally `getContext(native)`, and `writeResponse(ctx, response)`; use `createHostBridgeHandler()` for the shared lifecycle.                                                      | `createHostBridgeHandler.spec.ts`                                | `3f303787c8`, `3d1964e2fd`               |
| `PlatformKoaHandler`                                         | Public Koa-specific `PlatformHandler` subclass with v8 error and response-body workarounds.                                                                              | Removed; Koa uses the shared `PlatformHandler` through the Fetch route pipeline.                                                                                                         | Move host-specific work to Koa-native middleware or a bridge capability.                                                                                                                                               | Koa Fetch bridge specs                                           | `af858ddef2`                             |
| `PlatformHandler.flush()`                                    | Prepared a response and delegated its native write through the adapter during route compilation.                                                                         | Removed; route compilation never writes responses.                                                                                                                                       | Use `executeFetchContext()` followed by the host bridge writer.                                                                                                                                                        | `PlatformHandler.spec.ts`, Fetch pipeline specs                  | `80f652836b`                             |
| `PlatformHandler.prepareResponse()`                          | Applied response filters and exception conversion as a hidden `PlatformHandler` step.                                                                                    | Removed; the shared Fetch executor visibly applies filters, maps exceptions, then finalizes the response.                                                                                | Let `executeFetchContext()` own the response phase; custom host code receives its returned `Response`.                                                                                                                 | `createFetchHandler.spec.ts`                                     | `8f8270aec5`                             |
| `PlatformExpressHandler`                                     | Express-specific `PlatformHandler` subclass executed a controller-returned native middleware function.                                                                   | Removed; host bridges own explicit `native()` middleware while the shared `PlatformHandler` compiles portable handlers.                                                                  | Remove the subclass override; register framework middleware with the adapter's `native()` helper instead of returning it from a controller.                                                                            | `PlatformHandler.spec.ts`, bridge route specs                    | `58ff043b64`                             |
| `PlatformRequest.setBody()` / `setParams()`                  | Parser and bridge code could mutate request body and route parameters after context construction.                                                                        | Removed; `PlatformRequestAccessors` supplies host-owned values lazily when the Fetch context is constructed.                                                                             | Have a host bridge pass `accessors` to `createFetchContext()`; direct Fetch execution has no implicit parsed body, cookies, sessions, or files.                                                                        | `PlatformRequest.spec.ts`, `createContext.spec.ts`, bridge specs | `58ff043b64`                             |
| `PlatformKoaRequest` / `PlatformFastifyRequest`              | Public request subclasses adapted Koa and Fastify request objects through DI.                                                                                            | Removed; adapters supply framework capabilities through `PlatformRequestAccessors`, while `request.native` exposes the native object.                                                    | Use `request.native` for framework-specific code and configure a bridge accessor for portable values.                                                                                                                  | Koa/Fastify route bridge specs                                   | `4856cf65fb`                             |
| `PlatformAdapter.sendResponse()`                             | Adapter implementations finalized and wrote a mutable response through a legacy adapter callback.                                                                        | Removed; bridge route handlers write the `Response` returned by `executeFetchContext()`.                                                                                                 | Implement the write boundary in the host bridge with `writeFetchResponse(ctx, response)`.                                                                                                                              | Fetch route bridge specs                                         | `c71f38dfbc`                             |
| `PlatformAdapter.mapHandler()`                               | The shared `PlatformHandler` delegated every compiled handler to the active adapter.                                                                                     | Shared compilation produces portable handlers; Express and Koa map only mixed routes that contain explicit `native()` middleware.                                                        | Custom adapters should map handlers only at their native route-registration boundary.                                                                                                                                  | Express/Koa route bridge specs                                   | Pending commit                           |
