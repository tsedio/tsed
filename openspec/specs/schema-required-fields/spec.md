# schema-required-fields Specification

## Purpose

Define how `@tsed/schema` computes the `required` list of a generated JSON Schema when properties are marked optional, with the functional API (`s.*().optional()`) or with `@Optional()`, including properties inherited from a parent class.

## Requirements

### Requirement: Optional properties are removed from the required list

The JSON Schema generated by `@tsed/schema` SHALL NOT list a property marked optional in `required`, and SHALL keep every other required property.

#### Scenario: Functional API property marked optional

- **WHEN** an object schema is built with `s.object({id: s.string().required(), name: s.string().required(), description: s.string().optional()})`
- **THEN** its JSON Schema has `required: ["id", "name"]`

#### Scenario: Optional property listed in the object's required fields

- **WHEN** an object schema lists `id`, `name` and `description` with `addRequired()` and `description` is `s.string().optional()`
- **THEN** its JSON Schema has `required: ["id", "name"]`

### Requirement: A child class can make an inherited required property optional

`@Optional()` on a property of a child class SHALL remove that property from the `required` list inherited from its parent class, without changing the parent's schema.

#### Scenario: Child marks one inherited required property optional

- **WHEN** `Parent` declares `@Required() id` and `@Required() description`, and `Child extends Parent` redeclares `description` with `@Optional()`
- **THEN** `getJsonSchema(Child).required` is `["id"]`
- **AND** `getJsonSchema(Parent).required` is still `["id", "description"]`

#### Scenario: Child redeclares an inherited required property without @Optional()

- **WHEN** `Parent` declares `@Required() description` and `Child extends Parent` redeclares `description` with only `@Property()`
- **THEN** `getJsonSchema(Child).required` is `["description"]`

#### Scenario: Child makes the only inherited required property optional

- **WHEN** `Parent` declares only `@Required() id` and `Child extends Parent` redeclares `id` with `@Optional()`
- **THEN** `getJsonSchema(Child)` has no `required` keyword
- **AND** `getJsonSchema(Parent).required` is still `["id"]`
